Core Feature Modules

What it does

Six modules, one dashboard

Every feature works completely offline. No internet, no backend, no setup required.

📷

OCR License Scan

Point your camera at a physical license. Google ML Kit reads text on-device and auto-fills the registration form instantly.

On-device AI
🔍

QR Code Verification

Scan any registered license QR code to instantly verify if it’s genuine, currently active, or expired.

Instant Result
📝

Manual Registration

Register a new driver with license ID, full name, license class, and expiry date — with full form validation.

Offline Storage
✅

Authenticity Check

Enter a license ID or scan a QR to get an instant 3-state verdict: Active, Expired, or Fake.

3-State Result
🗃️

Driver Database

Browse all registered drivers in a searchable list with full profiles, status badges, QR codes, and dates.

Local DB
📋

Audit Logs

Every verification attempt is logged automatically with timestamps, outcomes, and the officer who checked.

Full History

Get started

Install in three steps

Android only. No Play Store needed — sideload directly from the GitHub release.

1

Allow Unknown Sources

Go to Settings → Security and enable Install unknown apps for your browser or file manager.

2

Download the APK

Tap the Download button above or visit the GitHub Releases page to get the latest demo APK (~94 MB).

3

Install & Launch

Open the downloaded file, tap Install, then open the app and log in with demo / demo123.
