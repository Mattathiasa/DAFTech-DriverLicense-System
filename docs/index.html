A complete driver license registration and verification platform. Register drivers, scan licenses with OCR, and verify authenticity via QR code — all in one app.

Download Demo APK View on GitHub

What it does

Everything you need to manage driver licenses

Six core modules, all accessible from the home dashboard.

📷

OCR License Scan

Point the camera at a physical license. Google ML Kit reads the text and auto-fills the registration form.

🔍

QR Code Verification

Scan a license QR code to instantly verify if it's genuine, active, or expired against the registry.

📝

Manual Registration

Register a new driver by filling in the license ID, full name, license class, and expiry date manually.

✅

Authenticity Check

Enter a license ID or scan a QR code to get an instant result: Active, Expired, or Fake.

🗃️

Driver Database

Browse, search, sort, and filter the full registry of registered drivers with status indicators.

📋

Audit Logs

Every verification is logged with a timestamp and result, forming a complete audit trail.

Getting started

Install in 3 steps

Works on any Android device — no account, no server, no internet required after install.

1

Allow unknown sources

On your Android device, go to Settings → Security and enable Install from unknown sources (or allow your browser to install apps).

2

Download the APK

Tap the Download Demo APK button above. The file is ~94 MB. Open it once the download completes.

3

Install & explore

Tap Install on the Android prompt. Open the app, log in with demo / demo123, and start exploring.
